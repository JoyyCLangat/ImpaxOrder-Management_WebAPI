# Order Management - Frontend

React frontend for the Order Management app, built with Vite.

## Run

```bash
npm install
npm run dev
```

The app runs on http://localhost:5173 and talks to the .NET API.

## What's here

- Customer list with order totals
- Customer detail view (lazy loaded)
- Form to create a new order
- JWT auth with a custom `useCustomers()` hook
